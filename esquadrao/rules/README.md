# Regras — sempre seguidas, não apenas consultadas

Diferente de `skills/` (conhecimento consultado sob demanda conforme o contexto), os arquivos em `rules/common/` são carregados sempre que este plugin está ativo. Mantenha-os curtos — cada linha aqui custa contexto em toda tarefa, então só entra o que precisa valer para 100% do trabalho, não para um caso específico.

- `common/coding-style.md` — convenções de nomenclatura e estrutura, resumo do skill `coding-standards`.
- `common/git-workflow.md` — formato de commit e fluxo de branch.
- `common/testing.md` — exigência mínima de teste antes de considerar algo pronto.
- `common/security.md` — os três erros que já se repetiram neste projeto, sempre no topo de qualquer revisão.
