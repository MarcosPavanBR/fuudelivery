# Fluxo de Git (sempre ativo)

- Um commit, uma mudança lógica. Mensagem no imperativo.
- Nunca commitar `.env`, backup de banco, ou arquivo de documentação de config com valor real — ver `skills/credential-hygiene` antes de qualquer commit que toque configuração.
- PR pequeno o suficiente para revisar em uma sessão — se está grande, considere quebrar.
